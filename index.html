What is ArithCalc?

Instead of a single result that disappears, ArithCalc keeps your whole calculation visible — like a paper tape you can edit. Type line by line, add labels, and change any number at any time. Every total updates instantly.

Features

  • Editable tape — fix any line, totals recalculate
  • Labels & comments on each line
  • Percentages (e.g. 650 + 10%)
  • Multiple documents
  • Undo / Redo & memory (M+, M−, MR, MC)
  • Light, Dark & System themes
  • Fully offline — no account, no tracking
